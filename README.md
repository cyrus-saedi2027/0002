# کلینیک ساسان: وب‌سایت

## استودیو سبک (`style-lab/`)

یک قالب ثابت (هدر، هیرو، خدمات و رزرو نوبت) که با هشت سبک طراحی اجرا می‌شود تا قبل از ساخت سایت کامل، سبک نهایی انتخاب شود.

| # | سبک | حس | فونت |
|---|-----|----|------|
| ۱ | پزشکی مدرن | آرام، شفاف، علمی | وزیرمتن |
| ۲ | لوکس | سینمایی، طلایی روی سبز تیره | مرکزی + وزیرمتن |
| ۳ | کلاسیک ایرانی | لاجوردی و فیروزه‌ای، طاق و نقش گره | امیری + وزیرمتن |
| ۴ | مینیمال | تایپوگرافی و شبکه، رنگ کبالت | نوتو کوفی + وزیرمتن |
| ۵ | حرفه‌ای سازمانی | سرمه‌ای، داده‌های زنده | IBM Plex Sans Arabic |
| ۶ | نرم و دوستانه (تصویر ۱) | کارت‌های گرد، خط‌چین، بنفش | استعداد |
| ۷ | پاستلی جسور (تصویر ۲) | حاشیه‌ی مشکی، سایه‌ی پله‌ای، پاستلی | لاله‌زار + وزیرمتن |
| ۸ | آرامش طبیعی | سبز مریمی، فرم‌های زنده | المسیری + وزیرمتن |

### اجرا

فایل `style-lab/index.html` را با یک سرور ساده باز کنید:

```bash
npx http-server style-lab
```

- سبک‌ها از نوار پایین صفحه عوض می‌شوند. روی دسکتاپ کلیدهای ۱ تا ۸ هم کار می‌کنند.
- `#noir`، `#brutal` و بقیه در آدرس، مستقیم همان سبک را باز می‌کنند.
- دکمه‌ی موبایل در نوار پایین، قالب را در قاب گوشی نشان می‌دهد (فقط دسکتاپ).
- «یادداشت طراح» برای هر سبک توضیح، پالت، فونت، امتیاز و مسیر پیشنهادی ساخت سایت را دارد.

### فنی

- HTML/CSS/JS خام، بدون مرحله‌ی build. انیمیشن‌ها با GSAP و ScrollTrigger، اسکرول نرم با Lenis (از jsDelivr).
- همه‌ی طرح‌بندی‌ها با container query نوشته شده‌اند، برای همین نمای موبایل داخل دسکتاپ هم واقعی است.
- بدون GSAP هم همه‌چیز دیده می‌شود و کار می‌کند. با تنظیم «کاهش حرکت» سیستم‌عامل، انیمیشن‌ها خاموش می‌شوند.
- آیکون‌ها از Lucide (مجوز ISC) هستند؛ آیکون دندان به همان سبک کشیده شده است.
- نام پزشکان، آمار، تلفن و آدرس ساختگی‌اند.
